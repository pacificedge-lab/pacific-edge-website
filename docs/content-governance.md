# Content Governance

Every public content object carries a publication status.

- `draft`
- `review`
- `approved`
- `published`
- `archived`

Production pages render only `published` entries. Development renders non-archived entries so content can be reviewed in context.

Partners are additionally controlled by an explicit publication flag. Partner content should never appear publicly until the relationship has been approved for representation.

Work content should be reviewed for confidentiality before publication.
